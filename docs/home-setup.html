MRP-lite — Home Setup

Follow these steps when working from home.

Option A — Already cloned at home

  1. Open a terminal and cd into your MRP-lite folder.
  2. Pull the latest changes: 
    git pull
  3. Activate the virtual environment and update dependencies: 
    venv\Scripts\activate
pip install -r requirements.txt
  4. Run any new database migrations: 
    flask db upgrade
  5. Load the real data (suppliers, materials, etc.): 
    python scripts/setup_real_data.py
  6. Start the app: 
    flask run
    Then open http://localhost:5000 in your browser.

Option B — First time on this machine fresh clone

  1. Clone the repo: 
    git clone https://github.com/LucianMindrila/MRP-lite.git
cd MRP-lite
  2. Create a virtual environment and install dependencies: 
    python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
  3. Create a .env file in the root of the project (see below).
  4. Set up the database: 
    flask db upgrade
  5. Load the real data: 
    python scripts/setup_real_data.py
  6. Start the app: 
    flask run

.env file contents required

Create a file called .env in the project root with exactly this content:

FLASK_ENV=development
SECRET_KEY=any-random-string
DB_PASSWORD=localtest123
COMPANY_NAME=DT Solutions Ltd
COMPANY_ADDRESS=Units 3-4 Pearce Way, Gloucester, GL2 5YD
COMPANY_VAT_NUMBER=GB 000 0000 00
The .env file is gitignored — it never gets pushed to GitHub, so you need to create it manually on every machine.
